# 회사·직무 템플릿

discover가 공식 공고를 검증하면 이 구조로 회사와 직무 폴더를 만듭니다.

수동 입력 시 `00_JD.md`의 공식 URL·확인 시각·마감 원문·자격 근거를 먼저 채웁니다. 확인되지 않은 값은 추정하지 말고 `needs-review`로 둡니다.

상세 분석의 `01_JD분석.md`와 `02_직무적합성.md`는 [문장별 JD 매칭 형식](../../docs/runtime/JD_MATCHING.md)을 따릅니다. 요구마다 고정 ID를 부여하고 검증된 경험 또는 미확인 이유를 빠짐없이 남깁니다. `03_소재매핑.md`는 문항별 질문 의도·핵심 답을 정하고 요구 ID → claim을 연결합니다. 사람용 정본은 Markdown, `.work/`의 JSON은 변경 검사 기록입니다.
