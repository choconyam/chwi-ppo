# 회사별 지원 자료

회사별 자료는 `companies/<회사명>/` 아래에 정리한다. 같은 회사라도 지원 직무가 다르면 직무 폴더를 분리한다.

## 회사 목록

- [SK하이닉스](SK하이닉스/README.md)
- [LG그룹](LG/README.md): LG전자, LG CNS, LG에너지솔루션, LG디스플레이, LG이노텍
- [현대자동차](현대자동차/README.md)

## 기본 구조

```text
companies/<회사명>/
├─ 00_공식자료/          공고, 지원서 가이드, 회사 제공 자료
├─ <직무명>/
│  ├─ 00_JD.md           사용자가 넣은 직무 원문과 메모
│  ├─ 01_JD분석.md
│  ├─ 02_직무적합성.md
│  ├─ 03_소재매핑.md
│  ├─ 04_초안/
│  ├─ 05_사실검수.md       읽기 전용 사실 검수 결과
│  ├─ 06_수정본/
│  ├─ 07_최종검수.md       독립 최종 검수 결과
│  └─ 최종/                최종 검수 PASS 문서
└─ README.md             회사 내 자료와 지원 현황 인덱스
```

공통으로 재사용하는 프로젝트 README와 성적표는 저장소 루트에 둔다.

신규 파이프라인은 `profile/`의 `검증됨` claim만 지원서 근거로 사용한다. 기존 회사 폴더의 과거 파일명은 보존하되 새 작업부터 위 구조를 적용한다.
