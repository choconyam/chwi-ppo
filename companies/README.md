# 회사별 지원 자료

실제 회사·직무별 산출물은 로컬에서만 관리하고 Git에 포함하지 않습니다.

```text
companies/<회사>/<직무>/
├─ 00_JD.md              공식 공고 원문·링크·마감·문항
├─ 01_JD분석.md          JD 자체 분석
├─ 02_직무적합성.md      프로필과 비교한 지원 게이트
├─ 03_소재매핑.md        문항별 claim-id 배정
├─ 04_초안/
├─ 05_사실검수.md        읽기 전용 검수 결과
├─ 06_수정본/
├─ 07_최종검수.md        Sol XHigh 독립 검수
└─ 최종/                 최종검수 PASS만 저장
```

`00_JD.md`는 discover 단계가 공식 원문을 확인해 만들며 이후 단계가 덮어쓰지 않습니다. 수동으로 시작할 때는 `_템플릿/`을 복사해 사용합니다.
