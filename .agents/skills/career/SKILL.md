# Career

사용자가 요청한 범위와 현재 파일 상태를 보고 필요한 스킬만 읽는다. 작성·검색·정정·일정 조회처럼 할 일이 명확하면 해당 스킬로 바로 가며 career를 추가 선행 단계로 만들지 않는다.

- 자료 최초 정리·변경·사실 정정: intake. 기존 프로필과 변경 계획을 먼저 확인한다.
- 지원할 기업/공고 탐색 요청: discover. 자소설닷컴 등의 목록 → 프로필 조건 → 공식 세부 JD → 추천 순서다.
- 이미 선택한 JD 지원서 작성: apply. 공고 캘린더 등록을 기다리지 않는다.
- 상태/일정 표시·갱신 요청: track.

신입으로 고정하지 않는다. 프로필의 신입/경력/둘 다/미정과 실제 경력 범위를 사용한다. 한 조건이 미확인인 경우 관련 자격 판단만 보류하고 가능한 다른 작업을 진행한다.

단순히 다음 할 일을 물으면 현재 단계와 필요한 다음 입력을 짧게 알려준다. 전체 흐름을 맡겼으면 승인된 범위에서 이어서 실행한다. intake 완료만을 이유로 전체 기업 검색이나 캘린더 재생성을 자동 시작하지 않는다.

현재 메인 모델이 기본 실행자다. 역할별로 호출을 나누지 않고 간단한 작업은 끝까지 직접 처리한다. 큰 독립 작업의 위임과 요청된 독립 검수는 AGENTS.md의 기준을 따른다.
