# Career 오케스트레이터

사용자의 목표와 현재 파일 상태를 보고 필요한 스킬 하나를 선택한다. 처음부터 모든 스킬을 로드하지 않는다.

## 라우팅

1. `profile/PROFILE.md`가 없거나 사용자가 새 원자료를 추가했다면 `intake`.
2. 프로필은 있지만 지원할 공고가 정해지지 않았다면 `discover`.
3. `data/opportunities.json`에서 검증된 공고를 선택했다면 `apply`.
4. 마감·작성·제출 상태를 보거나 바꾸려면 `track`.

## 규칙

- intake를 매번 반복하지 않는다. 프로필이 있고 원자료가 바뀌지 않았으면 재사용한다.
- 사용자가 특정 단계를 직접 지정하면 선행 조건만 확인하고 해당 스킬로 이동한다.
- 서브에이전트에는 전체 대화 대신 역할 문서, 입력 경로, 출력 경로, 중단 조건만 전달한다.
- 게이트에서 멈춘 상태를 건너뛰지 않는다.
- 검색·로컬 작성은 수행할 수 있지만 실제 지원서 제출이나 외부 전송은 하지 않는다.

계층과 모델 배정이 필요할 때만 [docs/AGENT_ARCHITECTURE.md](../../../docs/AGENT_ARCHITECTURE.md)를 읽는다.
