# chwi-ppo 1.1.1

## 변경 사항

- 현재 대화에서 선택한 모델이 기본 작업을 직접 처리합니다. 명백히 큰 독립 작업만 나누어 맡깁니다.
- 간단한 경험 정정과 지원서 수정은 해당 내용부터 처리하며, 이미 제공된 지침·근거를 반복해서 읽지 않도록 했습니다.
- 공고 URL을 지정하면 해당 공고부터 확인합니다. 조회만 요청한 일정 데이터는 재생성하지 않습니다.
- 지원서에 사용하지 않은 경험의 수정이나 근거 위치의 줄 번호 변경 때문에 기존 검수 결과가 불필요하게 무효화되지 않도록 했습니다. 실제 사용한 근거나 본문이 바뀌면 기존 검수 결과를 그대로 사용하지 않습니다.
- 검수 전 초안을 먼저 제공하며, 독립 검수는 요청할 때만 실행합니다. 면접 대비와 학술 재감사는 제출 전 검수에 포함하지 않습니다.
- README와 시작 안내를 현재 실행 방식에 맞췄습니다.

이전 형식으로 저장된 검수 기록은 호환성 확인 과정에서 한 번 무효화될 수 있습니다.

## 설치·업데이트

- 처음 사용한다면 첨부된 `chwi-ppo-v1.1.1-release.zip`을 풀고 `AGENTS.md`가 있는 폴더를 Codex 또는 Claude Code에서 엽니다.
- Git으로 받았다면 공용 파일에 로컬 수정이 없을 때 `git pull --ff-only`로 갱신합니다.
- ZIP으로 받았다면 `update-chwi-ppo.cmd`를 실행합니다. `run-dashboard.cmd`에서도 24시간에 한 번 새 릴리스를 확인합니다.
- 개인 자료와 로컬 설정은 보존해야 합니다. 새 ZIP을 기존 폴더 전체에 덮어쓰지 마세요.
- npm 배포나 별도 npm 설치는 필요하지 않습니다.
